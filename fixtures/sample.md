# 書くことに、集中する。

Astroの記事を、見たまま編集できます。**大切な言葉**を強調したり、*少しニュアンス*を加えたり。

## 記事づくりをシンプルに

- 見出しやリストを直接編集
- 日本語の文章をそのまま入力
- 記事の情報もひとつの画面で管理

1. 文章を書く
2. 画像を追加する
3. いつもの操作で保存する

> 小さな気づきを、ひとつの記事に。

[Astroのドキュメント](https://docs.astro.build/ja/)や`src/content/`も参照できます。

```typescript
const message = 'こんにちは、Astro！';
console.log(message);
```
